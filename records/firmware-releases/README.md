# SNORR firmware releases

Current development baseline: **[0.1.0](0.1.0.md)**, established 2026-10-23.

Use `0.1.1` for fixes and `0.2.0` for the next development feature milestone;
use `1.0.0` for first accepted production. No beta suffix is required. Keep
upstream Meshtastic version, source SHA, build target, image checksum and saved
configuration separately identifiable.

The 0.1.0 entry is a source and existing-fleet snapshot. It does not certify a
uniform installed build. Future releases add immutable entries here with exact
target manifests and changes since the previous release; do not overwrite old
assets or historical installation evidence.

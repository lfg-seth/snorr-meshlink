## Owner request — 2026-10-19

On desktop, clicking a node should make the main map show only that node's neighbor signal connections, even when Show signal is off.

## Requested behavior / future acceptance

- Selecting a node shows its available mapped neighbor signal connections on the main map regardless of the global signal toggle.
- While selected, hide signal connections unrelated to that node.
- Selecting another node switches the displayed connections to that node's neighbors.

Deselect behavior and interaction with the global toggle after selection clears remain to define when activated. Mobile behavior is outside this request.

# Roadmap

Status as of 2026-10-12. These are checkpoints, not promised dates.

| Checkpoint | Evidence needed to move forward | State |
| --- | --- | --- |
| Project record | Git, project brief, local decisions, and record templates | Established |
| Inventory and pilot needs | Owned hardware counted; pilot size, position age, and mission duration recorded | Next |
| Network and firmware choice | Primary-source comparison matched to hardware; configurable behavior checked before a fork | Open |
| Bench trial | GPS reports, relay path, standalone operation, dispatch ingestion, and outage behavior demonstrated | Pending decisions |
| Field pilot | Route and acceptance criteria agreed; position delivery and power measured | Pending bench evidence |
| Repeater installation | Suitable coverage, site permission, environmental/power design, and maintenance plan established | Pending pilot evidence |
| Member rollout | Repeatable node setup, handout/training workflow, support, and inventory assignment | Pending pilot evidence |
| Reporting and funding | Dated expense evidence, measured outcomes, and shareable project narrative | Capture throughout |
| Law enforcement expansion | Separate stakeholder requirements and interoperability scope | Later |

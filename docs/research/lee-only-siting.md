**Why the hop count matters.** A member fix first received by R011 and repeated by R011, Sawmill and R006 uses all three forwards. The same applies to Champion via R006 South, Macks via R006 South, and the northwest R006 move via R010. A member fix first heard by a more distant radio in the connected group may require a fourth forward to reach dispatch. Seven Mile uses only R011 and the ridge, leaving one forward available inside the group. The existing R006 pin → R010 → G001 route would also spend an extra forward if used behind Champion.
